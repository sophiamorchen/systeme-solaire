# 🌌 Système Solaire en Sass  
Un projet visuel simple pour représenter le système solaire en Sass.

---

## 🪐 Description

Ce projet recrée une représentation stylisée du système solaire avec l’aide de Sass. 
Chaque planète tourne autour du Soleil en orbite. 
Cela montre ce que peut faire Sass en termes d’animations, de boucles et de structure de code.

---

## 🎯 Mes objectifs étaient de: 

- Comprendre l’organisation d’un projet Sass
- Utiliser des boucles Sass pour afficher les planètes automatiquement
- Travailler avec des  animations CSS
- Approfondire la construction d'un projet avec HTML / SCSS
- Créer une interface visuellement agréable sans JavaScript

---

## 🛠️ Technologies utilisées

- HTML5
- SCSS (Sass)
- CSS3 (keyframes, transforms, animations)
